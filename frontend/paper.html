Como funcionará com dinheiro real (fase 3)

Ainda não implementado — só a explicação.
1) O bot terá uma hot wallet própria (Solana) e uma conta Hyperliquid própria, com pouco saldo. Nunca a tua carteira principal. A chave fica só no servidor, nunca no browser nem no repositório.
2) Adicionar fundos = enviar USDC/SOL da tua Phantom para o endereço público da hot wallet do bot.
3) Levantar = o bot envia só para um endereço pré-aprovado (a tua Phantom ou BlueWallet), com limite diário.
4) Chaves com o mínimo de permissões (na Hyperliquid, uma API wallet que pode negociar mas não levantar).
4) Trades reais só com LIVE_TRADING=1, depois de 4–8 semanas de paper 24/7 com resultado positivo vs. hold SOL.
A tua Phantom continua só tua; o BlueWallet fica como cofre BTC.
